Qué iría acá cuando exista:

> `CONTRIBUTING.MD` menciona OpenAPI como "contrato compartido" cuyos cambios no deben afectar en
> silencio a otros integrantes, y usa de ejemplo una rama `feature/TC-12-openapi-schema-quotes`. Eso
> parece una plantilla heredada; **confirmar con el equipo si OpenAPI es parte del alcance**.
